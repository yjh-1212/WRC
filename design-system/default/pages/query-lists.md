# 查询与列表页面规范

本规范以用户确认的上下分区参考图为依据，覆盖查询类页面。与 MASTER.md 中旧的单卡片布局冲突时，以本文件为准。继续使用项目现有 Vue 3、Element Plus 和 Lucide 组件。

## 页面结构

1. 顶部导航和面包屑维持现有结构。
2. 上方 `QueryPanel` 独立白色卡片：每个条件使用 `QueryField` 显示标签，末尾统一为查询、重置。
3. 下方 `ListPanel` 独立白色卡片：不显示列表标题和顶部条数；有新增、生成、导出及排序等业务操作时，仅在右侧保留紧凑操作区。没有操作时直接显示表格，分页与条数保留在底部。
4. 不恢复独立的整页标题、说明及刷新栏。页面的语义标题继续供读屏和浏览器标题使用。
5. 数据地图、轨迹和分析图表保留原有业务结构，查询条件仍在结果上方。

## 视觉参数

- 冷灰背景、白色卡片、蓝色操作与重点数字；卡片边框 `#e4e9f0`，圆角 10px。
- 卡片间隔 20px；桌面查询卡片内边距 24px；列表内边距 20px，操作区底部间距 16px。
- 条件标签和输入内容 14px；条数与表头 13px；表格内容 14px。
- 查询控件高度 38px；列表业务按钮最小高度 36px。查询按钮使用浅蓝底，主要业务按钮使用蓝色实底。
- 表头使用 `#f6f8fb`，行分隔使用 `#edf0f5`；单元格竖向内边距 14px，双行身份信息区分主次。
- 不为没有来源的数据补造统计值；加载失败时不显示误导性的零条汇总。

## 交互和适配

- 查询区使用原生表单，Enter 执行查询；重置清空文本与可选条件，并复位分页。
- 日期条件恢复页面定义的初始范围；必选查询对象保持合法值。
- 保留现有查询联动、权限、批量选择、业务操作、错误重试和弹窗行为。
- 1100px 以下条件换行；720px 以下标签和输入对齐为单列，查询按钮位于末行右侧。
- 窄屏表格在自己的容器中横向滚动，不撑宽整个页面。

实现入口：`apps/web/src/components/QueryPanel.vue`、`QueryField.vue`、`ListPanel.vue` 与 `apps/web/src/query-layout.css`。后续新增查询页应复用这些组件，避免另写独立的查询工具栏样式。
