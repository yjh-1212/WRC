# 省级驾驶舱

## 目标与入口

面向省级监管人员，在值守时先了解规模与在线状态，再定位风险集中地市，最后进入风险核查和协同督办。用户已指定在「全省工作台」之后增加独立一级导航「驾驶舱」，路径 `/province/cockpit`，仅省级监管且有 `dashboard:view` 权限的账号可访问。

## 参考与视觉约定

- 地图参考 `JiaoNeng_v0.2/client/cockpit-map.jsx`：高德 JSAPI 2.0、二维正北视图、`amap://styles/blue`，保留地理参照和道路层级。
- 面板参考 `liaoliang/jiashicang/src/components/CockpitPanel.vue` 与综合驾驶舱：SVG 切角细框、标题短划线、紧凑数字与柔和青蓝强调。按最新要求，面板默认完全透明，地图铺满左右面板背后；不透明度可以在风格设置中调整。
- 海军蓝 `#071426` 为底，面板 `#0b2039`，主蓝 `#6597ff`、青色 `#49c9d1` 表示运行和选中，暖橙 `#efb85a` 表示高风险，柔红 `#f28b83` 表示重大或逾期。
- 使用微软雅黑 UI 作为中文信息字体，Bahnschrift / Segoe UI 作为数值字体；4px 间距单位，左右面板各占约 22%，中心地图保持主要地理阅读空间。

| 左中 | 地市车辆分布 | 已开通地市在册车辆排行、在线率、在册数量 | 点击选择地市，地图和其他面板联动 |

## 数据口径与边界

数据来自已开通地市关联机构下的 Vehicle、VehicleRealtimeStatus、Enterprise、SafetyAlert，以及已派发的 ProvinceMatter。不引入随机数、推算增长率或模拟实时轨迹。地图展示 16 个地市行政区域及开通状态；未开通城市不冒充零业务城市。车辆按用途分组中未知用途归为其他，分组总数等于在册数量。软删除车辆不参与统计。

在线状态为台账最后上报状态，并非网络探活。运行数量读取在线车辆最后一次运行状态；今日里程仅汇总北京时间当日心跳记录的 `mileageToday`，并提供最近心跳时点，当日尚未上报时显示“—”。今日新增风险使用北京时间 00:00 起的发生时间；未闭环风险含历史尚未关闭事项。事项排除草稿；办结率为已办结 / 全部非草稿事项，逾期为未办结且已超过期限。

省级默认汇总全部已开通地市，选择地市后其他指标、风险和事项同时筛选；车辆分布列表保留全省地市供比较，选中项高亮。地图是区域态势地图，地市标记使用区域中心，不表示车辆实时坐标。不绘制无事实依据的运输飞线。

- 地图采用本地山东省地市行政区数据，地市区块和标记支持选择；地图图层可切换行政区、地市名称和风险标记，可缩放或恢复全省视角。
- 按用户最新要求移除顶部六项统计条，仅保留驾驶舱标题和工具栏。高德 Logo 与版权角标仅在当前省级驾驶舱隐藏。
- 地图全幅铺在透明左右面板下方，按 JSAPI 的上、下、左、右顺序设置适配留白；同一个地图实例随数据更新，不在轮询时重建。窗口尺寸与面板宽度变化后重新适配区域。
- 按最新要求，右上角移除暂停/播放、手动刷新和 AI 入口，仅保留时钟、风格设置与全屏。数据仍自动刷新（默认30秒，可在设置中调整为10至120秒）。刷新失败保留上次数据并标明失败；初次失败不显示为零指标。
- 选择通过 URL `cityCode` 保留，刷新后恢复；选择未开通地市说明未接入台账，数值显示为缺少数据。
- 浏览器验证 1920×1080 与 1440×900 桌面大屏、地市联动、复位、图层开关、深链接、权限拒绝、加载失败重试和退出释放地图实例。较窄窗口采用地图在上、面板顺序排列，保证内容可读。

## 共享风格设置

右上角滑杆图标打开「大屏风格设置」，参考辽粮 StyleSettings 的组织方式，提供搜索、分组折叠、四个内置预设、恢复默认、自定义预设保存和删除。共40个实际生效参数，覆盖左右面板、整体主题与背景、文字与指标、面板与布局、图表、地图外观、地图标注、动效与刷新。二维地图不提供不存在的立体高度或光源设置。

「左右面板」分组置顶且默认展开，可统一设置六个面板的背景颜色、透明度。透明度以0%～100%展示，0%为不透明、100%为完全透明；后端保持原有0～1的 `panelOpacity` 存储，与旧配置兼容。背景色仅改变面板底色，文字和边框保持清晰。

调整仅在当前页面预览，取消关闭恢复已保存风格。省级管理人员可将设置保存到服务器，其他省级驾驶舱页面在前台每5秒读取共享版本，恢复焦点时立即读取。普通省级浏览账号可以预览，但不能保存共享设置。当前范围是省级驾驶舱，不改变市级驾驶舱。

配置存于 `CockpitAppearance` 的 `province` 单行，迁移 `20261028160000_cockpit_appearance`；采用版本比较后原子更新，防止并发覆盖。冲突时保留预览，读取最新版本后由用户核对并再次保存。后端严格校验颜色、范围、枚举、开关及未知字段；每次共享修改记录审计日志。每个省级驾驶舱最多12个自定义预设，另存预设不自动改变已保存的当前风格。

新增验证：80项单元测试通过；共享风格接口27项检查通过；双浏览器验收覆盖私有预览、取消恢复、保存同步、刷新保留、自定义预设与删除、版本冲突保留草稿、透明面板和统计/地图角标移除。截图位于 `test-results/province-appearance/`。

## 地图配色与首屏

默认风格为「深蓝监管」：背景 `#0b1d34`、渐变 `#12294a`、边框 `#6e96de`，图表使用蓝色层次。底图保留 `amap://styles/blue`，增加「地图色调」选项；默认「统一深蓝」先以灰度、褐色调统一底图色相，再应用亮度0.75、饱和度4、色相偏移170°，使陆地、水域、道路和行政区保持深蓝色系。「原始底图」可恢复不带统一色调的底图。参数可在风格设置中调整，已将深蓝方案保存到当前服务器共享配置，保留用户的面板透明度。选中地市的填充沿用区域颜色，不再固定叠加青绿色。

首屏读取共享风格及业务范围后，复用市级 `AmapCityEngine` 初始化原生高德地图。取消全视口像素采样、固定稳定等待和大型居中加载遮罩，使用页面背景及轻量连接提示。省级视图通过 `KeepAlive` 以账号为边界保留地图实例，离开页面暂停数据与共享风格轮询，返回时更新业务数据并恢复地图尺寸；下钻只更新当前范围、覆盖物及车辆位置。本地167KB山东边界在页面会话中缓存，省市地图共用，不加载全国边界；也不在每层或每次返回时重复创建地图。地图资源异常仍可重试，共享配置读取失败也保留重试入口。

`tests/e2e/province-map-appearance.cjs` 在真实高德SDK中延迟共享配置，检查配置未到达前不绘制地图；用非默认底图验证原生构造参数，再检查实际蓝色底图及滤镜、周期同步后无重复切换、读取失败后重试恢复。双浏览器外观验收进一步检查六个SVG面板的实际背景填充颜色和透明度，确认保存、跨浏览器同步与重载后效果一致。

`tests/e2e/province-cockpit.cjs` 和 `tests/e2e/province-map-loading.cjs` 保留原有命令入口，现均执行 `province-map-drill.cjs` 的实际业务与地图复用验收。

## 省市共用的层级地图与权限（2026-10-29）

已删除地图底部的“区域监管态势 / 山东省 / 全省总览 / 已开通地市”说明块。地图支持全省→地市→区县→企业→无人车五层，保留面包屑和逐级返回。区域标记来自辖区内台账车辆的聚合；省级显示地市参考中心、当前车辆位置和屏幕聚合，聚合点可点击放大。实体车辆点位保持数据库 GCJ-02 上报坐标，未定位车辆不伪造位置。区域图层使用已接入的运营区域。

新接口 `GET /api/dashboard/regulator/province-cockpit/map` 仅允许省级监管身份，以地市工作空间及其组织构造允许范围，再复用市级 `CockpitService.overview` 的区县、企业、车辆及最近历史轨迹逻辑。地市、区县、企业和车辆的组合均在后端校验，不信任路由中的 ID；暂停、未开通和空数据不填造业务数值。省级可跨市查看，市级原有接口继续使用工作空间隔离。

车辆层每5秒通过 `GET /api/dashboard/regulator/province-cockpit/map/vehicles/:id?cityCode=...` 读取状态，在同一个地图实例内更新位置、模型姿态和已观测轨迹。点击在线且运行中的车辆后，自动显示当前未结束行程的最近1000个真实定位点并跟随新上报；没有当前行程时，最近记录明确标注为最近记录，新增定位形成实时线。不使用历史记录模拟当前行驶。最近一次历史轨迹也可通过单独按钮查看。每30秒刷新完整车辆上下文与订单。悬浮窗显示最后定位时间和过期/离线状态。

按用户后续修正，地市下钻及车辆层保留市级左右面板：左侧运行总体态势、运营公司态势、当前分布；车辆层右侧为车辆属性、订单任务、行程轨迹。市级入口也保留原有两侧面板。点击无人车或其模型命中区域打开原生高德 `InfoWindow`，显示企业、区县、上报状态、行驶状态、速度、电量、里程和最后定位时间；悬浮窗锚定当前车辆位置，跟随地图平移、缩放及位置更新，关闭后不因自动刷新强行重开。市级保留返回全市入口，省级保留全省和逐层返回入口。

只读接口验收 `tests/api/province-map-api.cjs` 覆盖54项，验证省级16地市348辆车、完整下钻、状态接口及跨市非法组合，并验证济南市级、企业、运维账号无法访问全省接口；市级无法通过区县、企业或车辆 ID 读取其他市信息。浏览器 `tests/e2e/province-map-drill.cjs` 覆盖真实下钻、车辆悬浮窗、合成新定位形成轨迹、恢复侧栏与单一地图实例。一次本机验收首次就绪1098ms、返回255ms；这是本机当前数据和网络下的测量，不作为其他网络环境的速度保证。

## 山东三维地图与参数（最新）

原生地图始终使用JSAPI 2.0三维模式，底图遮罩仅包含山东16市和沿海岛屿，屏蔽省外路网及文字；限制地图中心在山东边界范围。总览按倾角、旋转角和左右面板留白适配山东投影轮廓，恢复全省按钮在已经处于全省层时也会复位。

独立行政区图层与高德同相机投影，采用向下拉伸的区域侧面表达厚度，车辆和道路仍贴合原始地面。行政区颜色、不透明度、边线颜色及粗细不再受底图调色滤镜影响。区域填充和厚度在11～12级之间淡出，街道近景保留道路、建筑和车辆，不遮挡实时轨迹。区域拉伸为视觉示意，不表示真实地形高程。

新增「三维地图」分组，默认展开，8项设置：启用三维、俯仰角0～65°、旋转角±180°、总览缩放偏移±1级、区域拉伸厚度0～30000米、侧面颜色、建筑显示、建筑高度倍率0.1～5。建筑使用原生`AMap.Buildings`，街道层级显示。全部48项共享设置兼容旧配置，补齐三维默认值并保留原有颜色及面板透明度，自定义预设同样补齐新字段；预览、取消、版本冲突和其他电脑同步沿用服务器配置流程。

验证：84项API单元测试；省市范围54项只读检查；真实浏览器覆盖五层下钻、车辆自动跟随、面板保留、山东遮罩、行政区参数、三维参数预览与双浏览器共享保存。截图在`test-results/shandong-map-scope/`及`test-results/province-map-drill/`。
