# 主体管理查询与列表布局 · 2026-10-30

按用户截图，将市级主体管理中的企业管理、车辆管理、安全员管理统一为上下两个独立面板。

- 上方查询区带字段标签，右侧为“查询”“重置”；复用现有 QueryPanel 与 QueryField。
- 企业管理保留关键词、企业状态；车辆管理保留关键词、企业、车辆类型、连接状态；安全员管理保留关键词、企业、审核状态。
- 下方列表标题、数量及登记/新增操作单独一行，车辆页的“厂商与车型”也移到列表操作区。
- 列表占满剩余高度，表格内部滚动，分页固定在列表底部，详情仍在右侧抽屉展示。
- 条件编辑不再自动请求；点击查询或在关键词输入框按回车生效并返回第一页。翻页、保存后刷新使用已提交条件，防止未查询的草稿条件改变列表。
- 重置清空所有条件并返回第一页。下拉框清空值可安全忽略，不会造成加载异常。
- 车辆企业参数链接继续生效。企业端安全员管理复用同一布局，并隐藏企业筛选。

## 验证
