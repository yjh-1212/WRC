# 驾驶舱市级二维地图调整

2026-10-30，按用户反馈将省级驾驶舱下钻后的市、区县、企业、车辆层级固定为二维正北俯视。省级卫星纹理三维地图保持原有实现。

## 变更

- 市级以下明确使用 AMap `viewMode: '2D'`，关闭俯仰、旋转、立体建筑、行政区侧壁和车辆 GLTF 模型，车辆以二维点位显示。
- 最终采用高德原生二维矢量底图 `amap://styles/blue`，与交能驾驶舱使用同一原生地图风格。先前的栅格瓦片统一染色方案压低了道路、地名对比度，已移除。
- 取消蓝色染色 SVG 和地图 CSS 滤镜，使用原生道路和文字样式，支持清晰的连续缩放；保持二维模式、关闭建筑块和车辆三维模型。
- 去掉行政区域填充、运营区域填充、两侧渐变和省界外遮罩，保留边界线、车辆聚合、运营区域和轨迹开关。
- 等待原生地图完成初始化后绘制矢量业务图层，慢速连接保留提示和重试；缓存地图保留容器尺寸，避免快速返回省级时底图初始化尺寸归零。行政边界层只使用二维投影，移除旧的三维侧壁计算。
- 保留车辆信息窗、实时轨迹、跟随、五级下钻和地图实例缓存；补充底图署名。

## 验证

`tests/e2e/city-2d-map.cjs` 使用真实高德 SDK 与原生矢量数据，检查青岛市二维模式、零俯仰和旋转、原生蓝色风格、无滤镜、无立体建筑及放大后的显示。

原生蓝色地图本次验收首次可操作耗时为 2924 ms，收到 35 个原生数据响应，没有 GLTF/GLB 模型请求或页面错误。原生矢量数据包含服务端合并的建筑、路网等数据包，但地图始终为二维，建筑显示关闭。该耗时是本地本次测试结果，外部地图服务网络条件仍会影响加载时间。
