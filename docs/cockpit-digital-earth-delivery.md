# 数字地球驾驶舱改造记录

## 2026-09-22 地球材质与省级构图优化

- 国家级下载并接入 NASA Blue Marble 2004 年 9 月无云地表纹理（5400×2700、约 1.7 MB）。资源在 `apps/web/public/textures/earth/`，原图不变，通过影像参数、低透明蓝色材质与相机相对光照统一色调。背景影像不是实时卫星数据。来源、使用说明见同目录 README。
- 国家初始相机改为 22500 km、俯视完整球体；中国区域半透明着色并保留地表细节，减少常驻标签，背面标注通过地球遮挡判断隐藏。保留完整行政面选取和排行联动。
- 省级默认本地行政立体底图，不加载在线卫星瓦片：9 km 制图抬升（仅视觉夸张，并非实际地形）、较暗侧壁、薄边界；上海、江苏、安徽、江西、福建提供低对比背景参照。业务色阶来自当前指标，风险色仅用于风险专题；缺报仍保持灰色。
- 两侧面板改为低对比透明渐变、细标题线和非等高布局，减少装饰编号与粗边框，突出总量、趋势和排行。市级原有下钻、图例、跟随、回放、地图工具保持。
- 修复开发环境纹理错乱的根因：Cesium 1.124 的宽松依赖实际安装了 engine 13.1 与 widgets 使用的 engine 14，而插件提供 1.124 Worker。开发入口改为相同版本官方 ESM bundle，与生产 bundle/Worker 对齐；未修改依赖包或锁文件。
- 底图异步切换增加请求代次保护，旧请求不会把上一级影像插入新场景。纹理失败时回退本地内置影像。行政几何只对显示边线作小容差简化，原始 GeoJSON 及填充几何不改动。
- 本轮没有增加数据库记录，没有加入前端硬编码业务统计。

验收：前端类型检查、生产构建、2 项车辆聚合单测、3 项边线简化单测、驾驶舱 API 回归通过；生产构建仍有现有通用 vendor 包体积告警。Playwright 在 1920×1080 和 1440×900 检查五专题、国家→省→市→区县→企业→车辆、跟随/轨迹回放、二三维切换、图层和全览，未捕获运行错误，画布保持复用。最终一轮本机市级切换约 1.06 秒、瓦片完成约 2.90 秒（非 SLA）。已人工查看国家、省、市实际截图；最终截图在 `test-results/digital-earth/`。

## 展示与交互

- 国家：本地数字地球、中国省域专题着色；综合态势、区域对比、风险监管、车辆结构、数据质量五个专题。地图与排行共享区域选择，再通过详情进入省级。
- 省级：浙江 11 市行政面，2.5D 倾斜视角；城市运行支持车辆数、在线率、运行数、企业数、里程指标切换。只有接入明细的杭州市开放市级入口，其他城市展示数据库汇总。
- 市级：区县→企业→车辆下钻、原有主题、状态图例、运行区域、路权线、历史轨迹、起终点、回放和跟随。侧栏使用当前范围统计，不再把全市车辆结构放到单车页面。
- 三层共享一个 Cesium 实例；保留右侧地图工具栏的 DOM 结构、图标和位置。返回上级恢复相机与选中区域，专题层开关和底图选择分别记忆。
- 左右面板统一为低对比半透明样式，趋势改为面积折线；缺报日期断开，不补零；移除无业务来源的装饰性省际飞线。

## 数据与初始化

新增可空字段 `CockpitRegionSnapshot.vehicleMetricsJson`，存放分车型汇总。接口不再按车辆占比临时推算在线数、风险数、里程等；缺少车型明细时该区域标记缺报。

执行 `pnpm db:seed:cockpit-digital`：只补充近七日缺失快照，不覆盖已有快照。本次新增 45 条，第二次执行新增 0 条。新增数据的 `sourceType=DEMO`，来源为“演示数据 · 数字地球初始化”。车型数据仅在初始化脚本生成一次并落库；前端没有演示统计常量。不能将这些演示快照作为真实监管报送。

全市规模保持现有数据库车辆数，未因本次视觉改造批量增加车辆。国、省接口不返回城市地图明细。下钻请求并行、同请求去重、30 秒内复用，点击接入地区后预取下一层数据；轮询不重置相机。城市地图仍依赖在线高德瓦片，网络慢会影响清晰瓦片到达时间，业务标记先显示。

## 验证

- `node tests/api/cockpit-digital-api.cjs`：验证六种筛选口径、三级总量联动、数据库分车型分配、风险范围及汇总接口无车辆明细。
- Playwright：1920×1080、1440×900；国家五专题、区域指标切换、国家→浙江→杭州、区县→企业→单车、跟随、回放、返回、车型筛选、接口失败提示及恢复、同一个画布复用，以及二三维快速切换、图层显隐、指标光柱、全览恢复。最后一轮通过，浏览器未捕获运行错误。测试截图在 `test-results/digital-earth/`。
- 本地验收曾测得约 1 秒完成市级视角切换，约 2.8 秒完成底图瓦片；此为本机单轮测量，不是生产 SLA。

## 接入边界

- 未提供合法城市建筑 3D Tiles 数据，未用随机建筑冒充真实城市模型。可配置 `VITE_CITY_3DTILES_URL`，在进入市级时加载真实建筑并作蓝色主题渲染；失败时保留道路和业务图层。
- 接口可用率、重复率等尚无采集源的质量指标明确显示“暂未接入”。城市缺少近期日报时，第二面板明确切换为数据库当前车辆状态分布，不生成虚构历史趋势；已有轨迹/日报未改动。
- 初始化脚本只可修复自身 `DEMO / 演示数据 · 数字地球初始化` 记录的分车型取整分配；在线数不超过在册数、运行数不超过在线数，分项加总保持与落库汇总一致。
- 地理资源来源记录于 `apps/web/public/geo/README.md`。正式发布需审核底图授权、行政区边界及地图审图要求。
- 本次无需新增前端依赖，迁移仅增加可空字段。Windows 上 Prisma 引擎 DLL 可能被开发服务锁定；修改生成客户端前应停止对应后端监听器，再生成并重启。当前客户端字段和接口已验证可用。
