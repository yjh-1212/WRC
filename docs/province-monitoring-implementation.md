# 全省监测开发交付（2026-10-29）

按已确认的三张设计稿实现，保持现有 Vue / Element Plus 工程，业务数据均来自现有数据库。省级驾驶舱继续使用独立的大屏样式。

## 页面与入口

| 页面 | 路径 | 已实现功能 |
| --- | --- | --- |
| 运行监测 | `/province/monitoring` | 地市、企业、车辆、运行状态、风险筛选；车辆状态分组；列表与山东地图联动；聚合车辆标记、单车悬浮窗、告警详情、风险通报 |
| 车辆监管档案 | `/province/vehicles` | 按车辆编号、统一编码、VIN、设备编号检索；一车一档抽屉；档案总览、运行轨迹、运行记录、事故与视频、告警违规、通行许可六个档案视图 |
| 事故回溯 | `/province/accidents` | 事故查询与分页；前后5/15/30分钟证据窗口；视频通道选择；原始轨迹、速度、电量；视频覆盖与缺口；共同时间线、倍速、跳转事件、属地反馈与关联督办 |

顶层“全省监测”只保留上述三个入口。根据后续确认，三页中重复的横向功能导航已移除，查询条件区直接作为页面内容起点。旧风险监测地址转到运行监测的全部告警视图；旧综合查询中的车辆、事故和告警链接保留对应对象及城市上下文，自动进入新页面。企业、许可、违规的原通用查询地址继续兼容，但不作为新菜单入口。

## 数据和权限

- 省级查询接口独立放在 `/api/province/`，同时校验监管端、省级身份和具体业务权限。城市范围限制为山东省工作空间及其组织。
- 地市和企业继续走原有属地接口，不能访问省级接口或其他市的数据。省级不执行事故认定等属地业务写操作，可转入协同督办。
- 档案中的轨迹、运行记录、事故、告警、违规、许可按各自权限返回；无权限的档案视图不显示。
- 所有列表均在服务器筛选和分页；地图最多5000辆，轨迹最多5000点，超限明确提示。按时间查询轨迹最多7天。
- 在线、运行等状态来自最后一次遥测；超过10分钟未上报会标注。运行中与离线异常可以因过期遥测同时命中，不把历史心跳改写成当前实时在线。
- 原始轨迹按采集时间显示，不使用道路纠偏改写证据。时间线附近60秒内没有定位点时不显示虚假的位置和遥测值。
- 地图使用原生高德2D地图和已缓存的山东边界，聚合省域车辆，选中车辆后放大；进入实时跟踪复用现有驾驶舱。查询和时间游标变化不会重新创建当前地图实例。

## 事故录像接入约定

现有5条事故记录没有可用录像。本次已实现录像元数据提交、权限校验、播放器及时间同步，未绑定外部视频平台账号，也未向业务数据库填入演示视频。

所属城市或企业可在上报事故时附带 `videos`，或通过已有事故编号追加录像：

`POST /api/safety/accidents/:id/videos`

请求需要登录令牌和 `safety:accident:report` 权限，且事故必须属于当前账号的数据范围。省级、运维身份禁止提交。

```json
{
  "videos": [
    {
      "name": "前视事故录像",
      "channel": "FRONT",
      "url": "https://video.example.org/evidence/clip.mp4",
      "startedAt": "2026-10-28T09:31:00+08:00",
      "endedAt": "2026-10-28T09:41:00+08:00",
      "source": "企业视频平台"
    }
  ]
}
```

以上为接口格式示例，URL不代表已接入的视频源。通道支持 `FRONT / BACK / LEFT / RIGHT / SIDE / UNKNOWN`，每次最多20段、单段元数据时间跨度最多24小时。起止时间必须带时区。追加保留原有附件，并通过并发校验避免覆盖他人提交；审计记录提交人和数量，不写入完整签名播放URL。

录像地址应为浏览器能够访问和解码的 HTTP(S) 文件，优先提供支持 Range 请求的 MP4（浏览器支持的编码）或 WebM。页面不转码，也未集成厂商私有播放器；HLS等格式取决于浏览器的原生能力。相对 `/media/`、`/uploads/` 地址需要部署方已有对应文件托管，本次不提供新的文件存储服务。

旧附件仅有URL时支持独立播放，并标注缺少时间信息；没有采集起止时间时不伪造视频与轨迹的同步。未接入、录像缺口、资料格式异常和读取失败分别显示。视频平台若使用短期签名地址，需要在既有集成中更新有效URL。
