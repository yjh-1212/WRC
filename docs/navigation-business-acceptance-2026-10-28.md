# 省市平台职责与导航调整验收

本轮依据用户确认的省市分工实施。省级仅监管端，定位为全省监测、地市管理、协同督办和分析评价；市级承接属地业务，企业在本市工作空间使用企业门户。

## 已落地结构

| 门户 | 导航顺序 | 管理入口 |
| --- | --- | --- |
| 省级监管 | 全省工作台 → 地市管理 → 全省监测 → 协同督办 → 分析评价 | 平台管理，顶部末组 |
| 市级监管 | 监管工作台 → 主体管理 → 准入与许可 → 运行监管 → 安全监管 → 分析评价 | 管理设置，顶部末组 |
| 市级企业 | 运营工作台 → 基础资料 → 申请与许可 → 运行监测 → 安全管理 → 企业评价 | 企业设置，顶部末组 |

按后续确认，三端统一为顶部一级导航、二级下拉菜单、全宽业务内容。下拉按内容自适应宽度，同一时间仅展开一个；选择功能、点击外部或按Esc均收起。市级驾驶舱入口保留，进入后隐藏顶部导航并全屏显示。权限与菜单范围仍由各自账号确定。

完整叶子菜单和权限来自 `apps/api/src/auth/navigation.ts`。用户详情、资质、轨迹、运行记录、审批过程、事故回溯等收进主体、监测、申请、事件页面内部。旧链接保留参数并跳转到对应业务页；许可旧链接可通过精确ID查询恢复详情。隐藏详情入口仍按独立权限判断。

## 业务与权限

- 新增四类省级事项：风险通报、督办任务、跨市协同、应急统筹。支持草稿、派发、本市响应、反馈提交、省级退回及复核办结。全部状态、反馈和操作历史真实保存。
- 省级不能代替城市响应，也不能直接办理属地档案、准入审批、安全处置、企业评价和信用记分。省级可汇总生成监管报告；城市来源报告仅查询及导出。
- 市级工作台接收省级事项，只显示本市分派与反馈；其他城市的反馈、资源和联系人不会返回。全部城市反馈后，省级才可整体办结。
- 应急资源按城市登记，派发时占用，事项办结后释放；资源归属和正在使用状态受后端校验。
- 试点阶段管理按后续要求暂缓：移除菜单、页面及对外接口，旧链接转到城市管理，停止初始化及展示阶段数据。原有数据保留，不新增建设进度或阶段审核流程。
- 地市履责评价根据现有企业、车辆、接入时效和事项反馈计算，草稿需经省级发布。城市只能读取本市已发布评价；重新计算不会覆盖已发布结果。
- 市级机构、成员和业务角色保留城市隔离、管理员交接、最后一位管理员保护。审批流程在业务规则页内配置，本市角色可配置，本市流程可写，共享模板只读。
- 省级有限权限账号同样受委派上限约束，不能授予更高权限、维护更高权限人员或重置高级管理员密码；旧系统企业新增接口同样执行属地办理边界。市级管理员按全市范围履责，区县工作人员维持原辖区范围。
- 省级人员管理仅维护省级及运维身份；企业成员由市级或企业管理员管理，省级不提供企业端。
- 共享厂商与车型在省级“标准与规则”内维护，市级主体管理中只读查询；旧厂商、车型链接保留目录页内上下文。

## 数据与部署

沿用山东16市目录，已开通济南、青岛、临沂3市，共12家企业、348辆车。新增4类省级事项各1条、9项应急资源和按现有数据计算的3份履责评价草稿。此前3项试点记录已停用，仅保留历史数据。数据来源、构造口径及外部接入状态记录在 `docs/province-oversight-data-sources.md` 和 `docs/shandong-data-provenance.md`。

另定向修正358条旧地区业务字段，其中348个设备编号、5份资质证号和5条业务文本。重复执行变更为0，外键检查通过。全省地市表的“上报在线”与运行监测按最近上报状态同口径统计，评价的数据时效率仍按真实心跳计算。

`prisma/seed-shandong.ts` 已串联幂等省级事项初始化。迁移前备份为 `tmp/backups/regulatory-before-navigation-20261028.db`。浏览器和接口验证产生的临时事项按ID清理。

## 验证方式

- `pnpm build`：前后端完整构建。
- `pnpm --filter api test`：47项单元测试，8个测试套件。
- `pnpm test:api:oversight`：120项检查，覆盖省市菜单、职责、跨市协同、资源、发布、管理员权限上限、审批流程隔离及试点功能暂缓；结果 `test-results/navigation/api-verification.json`。
- `pnpm test:api:saas`：148项原有SaaS回归，覆盖开通、激活、授权撤回、材料下载、账号与管理员保护。
- `pnpm test:e2e:navigation`：覆盖三端菜单页面、导航上下文、下拉互斥与收起、控件交互和旧地址跳转。三端地图验证加载、车辆选择及1024/1440宽度切换；截图和结果保存在 `test-results/` 对应目录。

浏览器检查中修复了组合页继承旧布局后地图容器宽度为0的问题，同时补充地图正尺寸初始化、ResizeObserver及异步卸载保护，保留原3D和业务图层。

浏览器和接口验收读取环境变量 `TEST_PASSWORD`，使用已有本地验收账号；不在文档记录密码。SaaS回归会临时变更授权并使会话失效，应与浏览器回归串行执行。

## 本轮边界

数据接入与共享提供真实业务数据目录、字段及权限范围；外部交换接口仍需对接实际系统。应急统筹保存业务事项与保障资源，不发送车辆控制指令。企业数据接入状态按实际配置显示，未完成联通的接口保持未验证状态。
