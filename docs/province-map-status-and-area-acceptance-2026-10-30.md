# 车辆状态与城区运营区域验收

## 页面行为

- 省级三维总览、市级及后续二维地图共用同一状态定义：绿色运行中、蓝色待机、黄色已停驶、灰色已离线；未知状态使用紫色，仅在有相关数据时显示。
- 图例固定在地图左下方，数量按当前范围计算；离线位置说明为最后上报位置，不添加环境标签。
- 车辆选中后保留状态颜色，用外框强调选择；风险用外框表达，避免把离线等状态误染成运行颜色。
- 聚合按状态分组，位置锚定到一个真实成员坐标。聚合显示简短数量，悬停显示状态与数量。
- 六个城区运营区域为完整封闭面，范围覆盖相关街区。显示 3px 青色边界和 6px 深色底边，无填充遮罩；默认视野包含区域边界与车辆，避开侧边面板和左下图例。

## 验证记录

- 前、后端构建通过；API 20 个测试集、136 个测试通过。
- 省级地图接口 56 项检查通过，包括车辆区域包含关系、当前轨迹范围和跨城市、企业权限。
- 青岛二维地图检查通过：图例计数与 API 一致，车辆和聚合状态颜色一致，聚合符号处于真实成员坐标，边界清晰且无填充，浏览器无页面错误。
- 省、市、区县、企业、车辆下钻、信息窗、实时轨迹、跟随及缓存返回回归通过。
- 省级三维总览在 1920、1440、1366 桌面分辨率、暂停动效、缓存、影像重试及无 WebGL 备用视图检查通过，页面与着色器无错误。二维边界层不再调用三维投影。

脚本：`pnpm exec tsx prisma/align-shandong-road-network.ts --plan` 生成只读计划，`--apply` 备份后应用，`--verify` 校验。几何工具 `@turf/buffer` 仅用于离线数据准备，不引入前端运行依赖。
