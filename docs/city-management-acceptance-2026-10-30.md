# 地市管理改版验收 · 2026-10-30

按已确认的设计图实现，省级 `/province/workspaces` 页移除可见面包屑、页面标题和描述；保留屏幕阅读器标题。其他页面导航保持原有行为。

- 四项概况：全省地市、已开通、待开通、接入车辆。由完整城市目录与工作空间接口计算，搜索和状态筛选不改变全省统计。
- 城市列表工具栏右对齐：搜索、状态、重置、开通城市。开通按钮在搜索右侧，同一行展示；窄屏在工具栏内换行。
- 展示城市/行政编码、实际管理单位、授权模块、车辆数、管理员、授权状态与到期日期。管理单位从工作空间绑定的组织读取，不拼接默认名称。
- 保留调整授权、邀请管理员和核验恢复管理员流程及后端权限边界。
- 下方展示本地真实行政区边界的轻量 SVG 开通分布图、比例及待开通城市入口，不加载地图 SDK。点选城市会预填开通城市、管理单位及管理员账号。
- 只读人员隐藏管理操作，待开通城市入口禁用。概况请求失败显示“—”与重试，不显示伪零值。

验证结果：

- 前端类型检查及生产构建通过。
- API TypeScript 检查通过；SaaS 服务 15 项测试通过。
- 真实开通回归通过：校验必填、重名账号失败保留输入、成功开通、管理员立即登录及线下授权办理提示。临时测试城市与账号已清理。
- 浏览器验证通过：关键词/状态筛选、重置、统计不受筛选影响、预选城市与通用开通入口、授权/管理员弹窗、只读行为、失败重试，无页面脚本错误。
- 1920、1440、1366、390 宽度无整页横向溢出；表格在窄屏内部横向滚动。各尺寸小地图完整显示在概况卡片内。
