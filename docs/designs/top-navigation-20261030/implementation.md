# 顶部导航实施

日期：2026-10-30。依据用户确认的`02-approved-text-navigation.png`开发。

- 左侧使用用户提供的中国数联完整标识，原始透明PNG保存为`apps/web/public/branding/china-unidata.png`，文件与附件SHA256一致。仅通过CSS去除标识自带的透明边距，保持比例。
- 移除顶部旧卡车标识、旧平台名称和副标题；品牌首页链接仍以无障碍标签说明省级、市级或企业门户身份。
- 一级导航为纯文字，仅分组入口保留下拉箭头；下拉菜单保留原有图标与权限、层级、跳转和互斥展开逻辑。
- 桌面84px白色导航条，左右等宽预留区域，使整组菜单围绕页面中轴居中。采用Noto Sans SC，回退至苹方、微软雅黑；选中项为浅蓝圆角底与居中短下划线。
- 1280px及以下分为品牌/账号行和导航行，手机端导航可横向滚动。品牌回首页、账号退出和键盘导航保留。
- 共享于省、市、企业顶部导航，不改变各账号菜单权限与门户数据。

验证：前端类型检查及生产构建通过；省级菜单浏览器回归通过，1920/1600/1440宽度菜单中心偏差小于2px且完整可见；1024/390下拉定位、键盘操作通过。市级、企业顶部导航、菜单权限、1280/1024完整可见、手机下拉边界及品牌回首页验证通过，页面错误0。
