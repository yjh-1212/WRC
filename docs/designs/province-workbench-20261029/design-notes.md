# 全省工作台设计

日期：2026-10-29。范围：页面产品设计与图片评审，不修改业务代码。图中均为示例数据。

## 页面任务

省级监管人员进入工作台后，先判断需要自己复核的事项及逾期情况，再查看高风险事件和地市业务概况。以“哪些事项需要省级行动”为主线。监管事件由属地处理，省级在授权范围内查看、派发协同事项并复核反馈。

## 信息结构

1. 顶部主导航、面包屑和紧凑的页面标题/日期/刷新。遵循用户最新要求，不增加页内第二级菜单页签。
2. 一条六项概况：已开通城市、在册车辆、运营企业、上报在线车辆、在办协同事项、逾期事项。
3. 中间主区：左侧待办事项，右侧重点风险。待复核列表展示事项、责任地市、反馈完成情况、截止时间和复核入口。逾期通过标识强化，过滤器只切换同一事项集合。
4. 下方地市监管概况：开通状态、企业与车辆、上报在线、高风险、协同及逾期数量；点击运行监测或协同事项进入对应独立业务页面。

## 交互与指标

- “待复核”按已提交回执、需要省级复核的事项定义；“待响应”意味着等待地市响应，省级查看进展。逾期可以与两者重叠，不能将三个过滤器计数相加为总事项数。
- 总在办事项按事项ID去重；某事项关联多个地市时，地市表按承接关系统计。全省总数不能直接累加地市分派数。图中使用每市不同事项的简化示例，使总数8与3+3+2一致。
- 页面默认当前全省范围，工作台待办不受历史统计周期过滤。完整历史查询放在对应业务页。
- “复核”进入已有协同事项详情，对照地市反馈与材料后复核；不在首页一键办结。新建事项仅在拥有创建权限时显示。
- 重点风险仅展示有风险查看权限的高/重大、未闭环记录；查看详情定位同一告警对象，后续处置由属地承接。
- “上报在线”是来源状态，不能冒充已核实的实时在线率。查询汇总更新时间与车辆上报时刻分别解释；数据覆盖未经核实不能视为全省全部业务已接入。
- 空待办显示当前没有需要复核的事项并允许查看全部；空风险只表示授权范围内未查询到相应记录。请求失败单独显示重试，不显示为0。
- 不加入已撤下的地市履责评价、报告分发登记，也不增加与主导航重复的快捷菜单区。
