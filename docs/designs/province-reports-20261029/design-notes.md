# 监管报告设计

日期：2026-10-29。范围：产品与视觉设计图；不修改业务代码。画面数据为示例。

## 目的与页面

省级监管人员查找指定周期与单位的报告，核对生成时的数据快照，导出统计指标并登记线下分发。沿用“省域运行分析”的横向导航、蓝白浅色与紧凑密度。

- `01-report-library.png`：监管报告列表。关键词、分类、周期类型、生成单位、生成日期、分发登记筛选；列表呈现报告身份、统计周期、生成来源、生成时间和操作。
- `02-report-preview.png`：报告预览。左侧目录，右侧可读文档；包括报告信息、运行概况、趋势、安全态势与统计口径。

## 行为设计

- 生成报告：表单填写名称、周期类型（日 / 周 / 月 / 专题）、分类（综合监管 / 运行分析 / 安全态势）、统计起止日期。省级默认全省数据，不提供企业专项生成。默认建议上一完整周期，尚未完成的本期须明确实际截止日。
- 自动建议名称可编辑；运行分析进入时可携带周期。分发对象放到实际登记时填写，避免误以为生成即发送。
- 创建完成后进入预览；关闭表单前保留填写内容，提交中锁定重复提交，失败保留输入并重试。若以后改成长任务，补充取消与恢复机制。
- 查看报告按分类显示相应章节：运行分析不空挂安全章节，安全态势不空挂运行章节。导航目录与文档标题同步。
- 在线预览使用报告保存的summary快照，不随当前运行台账变化；明确生成单位、生成时间与统计期间。真实数据截止时间只有来源可验证时显示。
- 当前导出为CSV统计指标，不宣称已有PDF、Word或所见即所得导出。
- “登记分发”填写分发对象、登记时间并确认；只表示登记线下流转，不表示已经发送、送达或接收。已登记后展示登记对象与时间。
- 省级可以查看和导出属地报告；属地报告的分发登记仍由原生成单位维护。列表不提供批量勾选或没有落地能力的审核、发布、自动订阅、定时生成。
- 查询和分页服务端执行。无匹配显示清除筛选；初始无报告提供生成入口；读取失败显示重试，预览失败不展示0值报告。
- 数值保留单位；各量纲不放在同一数轴；自主运行里程占比用里程计算，不能标成任务完成率。缺失来源明确展示，不补成0。

## 证据与实施缺口

依据：`apps/web/src/views/RegulatoryReportsView.vue`、`apps/api/src/analytics/analytics.service.ts` 的reports/report/createReport/updateReport/exportReport及CreateReportDto/UpdateReportDto。

- 已有：关键词、分类与状态过滤，分页列表，报告生成、运行/安全summary快照、详情读取、CSV导出，分发状态、对象和时间；省级不能维护属地报告。
- 需扩展：周期类型、生成单位、生成日期过滤；独立阅读页及目录；表单成功转到报告；分发对象确认交互。当前后台分页已经具备，前端需要真正接通而不是固定拉取50条。
- 当前已有趋势保存在运行快照中，可用于报告趋势图；完整数据覆盖说明需接入端补充可验证的元数据。
- 无证据支持审批发布流程、自动邮件送达、收件回执、PDF/Word导出；本设计不将其画成既有能力。
