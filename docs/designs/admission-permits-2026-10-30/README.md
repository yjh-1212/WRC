## 最终设计图

1. [业务办理](01-business-processing.png)：上方查询，下面为待办/全部申请列表，按业务状态显示办理、签发与详情入口。
2. [通行许可](02-travel-permits.png)：显示许可、企业与车辆、许可类型、区域、运行条件、有效期及状态。
3. [通行区域](03-passage-areas.png)：区域列表，右侧抽屉展示大块运营区域的二维地图、关联企业车辆和运行条件。

三页保持无侧栏、顶部文字导航、无顶部统计卡片、上方独立查询卡片、下方列表占满剩余高度的布局。详情在右侧，不放在列表下面。

设计图中的名称、数量和地图为视觉示意，不作为实际台账数据。实现使用后台业务记录和真实二维地图，支持示范应用、变更、续期、退出、分车签发及许可状态管理；列表批量操作为导出，审批按事项逐条办理。详细范围以实现与验收记录为准。

业务办理图最终选中“全部申请”，因为可见行包含待审核、待补正、待签发及已办结等不同状态。
