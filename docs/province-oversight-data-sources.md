# 省级协同业务初始化来源

日期：2026-10-28。脚本：`prisma/seed-oversight.ts`。

范围更新：试点筹备、申报、审核、整改、验收暂缓，脚本已停止创建试点阶段记录；菜单、对外接口、目录和概览均不再提供该功能。此前初始化记录仅保留于数据库。

- 使用既有山东城市工作空间与真实数据库中的主体、车辆、许可、心跳、在线统计及事项回执作为关联及评价计算来源。
- 试点进度、风险通报、跨市核验、应急准备和资源目录为本地产品验证而构造的业务记录，不作为已发生的行政事实、真实政府通知、可直接调用的保障资源或实际联系人使用。
- 初始化不重置现有业务，固定业务编号与资源标识，重复执行不覆盖已流转事项、资源状态或试点阶段。
- 地市履责评价直接调用正式指标计算服务；四项口径为企业建档运行覆盖率20%、车辆许可有效率30%、数据时效率25%、省级事项按时回执率25%。无到期事项不扣回执分；无基础企业、车辆或数据记录的对应指标计0分。
- 当前月数据时效使用生成时心跳，历史月使用当月日在线率；已发布评价保持原结果，不因脚本重跑而覆盖。
- 对外接口尚需独立授权与联调，数据目录仅陈述本平台已有表和查询能力。界面不附加来源标签，来源记录保存在本文件供内部治理和后续真实接入时区分。
