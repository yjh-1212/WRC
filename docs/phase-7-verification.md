## 本地验收顺序

```bash
pnpm db:deploy
pnpm db:seed
pnpm test
pnpm test:db
pnpm build
pnpm dev
pnpm test:api
pnpm test:e2e
```

本轮实测结果：2 个单元测试套件共 6 项通过；6 个迁移已全部应用；API 验证覆盖 6 类角色和 6 组拒绝矩阵；Phase 1–7 E2E 全部通过。Phase 7 实测实时地图约 1.14 秒、安全态势地图约 0.91 秒进入可用状态（本机开发环境，非生产 SLA）。

`pnpm db:seed` 会重置开发数据库。全量 E2E 含创建和状态流转操作，验收结束后如需回到标准演示数据，再执行一次 `pnpm db:seed`。
