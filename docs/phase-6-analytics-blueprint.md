# Phase 6 分析研判实施蓝图

## 1. 范围与依据

本阶段在现有 Vue 3 + Element Plus、NestJS、Prisma/SQLite 与高德 JSAPI 项目上增量实现，不重建项目。业务范围来自需求说明书中的“运行数据分析、运行安全分析、事故数据分析、企业评价、安全画像、统计报表”和总提示词 Phase 6 清单。

## 2. 信息架构

监管端“分析研判”拆分为六个可直达路由：

| 页面 | 路由 | 核心任务 |
| --- | --- | --- |
| 运行分析 | `/analytics/operations` | 按时间、企业、车辆分析里程、频次、效率、能耗和自主运行率 |
| 安全态势 | `/analytics/safety` | 融合告警、事故、违规，分析趋势、类型、企业风险和空间聚集 |
| 事故回溯 | `/analytics/accidents` | 复现事故窗口轨迹与关联证据，形成监管结论 |
| 企业评价 | `/analytics/evaluations` | 配置指标规则、自动评分、复核发布、处理申诉 |
| 企业安全画像 | `/analytics/profiles` | 汇聚六维能力、监管事实和风险标签 |
| 监管报表 | `/analytics/reports` | 生成、在线预览、CSV 导出与分发日/周/月/专题报表 |

企业端提供 `/enterprise/evaluations/current`、`/history`、`/appeals` 和 `/enterprise/profile/safety`，只展示本企业数据。

## 3. 数据与状态模型

- 实时聚合：运行分析、安全态势和安全画像从运行记录、在线日报、告警、事故、违规、离线和应急数据计算，避免重复持久化派生指标。
- 评价配置：`EvaluationIndicator` 定义维度、指标键、权重和方向，`EvaluationRule` 定义区间与得分。
- 评价执行：`EvaluationTask` 状态为 `DRAFT → RUNNING → COMPLETED → PUBLISHED`；`EnterpriseEvaluation` 保存总分、等级、风险、维度分和透明评分明细。
- 评价申诉：`SUBMITTED → ACCEPTED | REJECTED`；受理后原评价进入 `UNDER_REVIEW`。
- 事故回溯：`DRAFT → COMPLETED`，保存证据摘要、原因、结论、建议和分析人。
- 监管报表：`GENERATED → DISTRIBUTED`，保存统计周期、口径快照、接收对象和生成/分发时间。

## 4. 评价口径

默认指标权重合计 100%，覆盖安全、合规、运行三个维度。系统按数据事实计算指标值，再按规则区间命中得分，最终按权重汇总：

`综合得分 = Σ(指标得分 × 指标权重 / 100)`

等级为 A（≥90）、B（≥80）、C（≥70）、D（<70），对应低、一般、较高、重大风险。页面必须展示指标值、权重、得分与命中规则，风险排序只用于差异化监管，不替代事故责任认定。

## 5. 可视化与地图

- ECharts 使用按需注册的折线、柱状、雷达等组件；图表容器支持 ResizeObserver 和减少动态效果偏好。
- 安全态势在高德地图叠加风险热力层，事故或重大事件增加显式点标记；地图 Key 与安全密钥继续从现有环境变量读取。
- 事故回溯复用现有轨迹组件与高德 MoveAnimation，展示事故前后证据窗口，不复制地图实现。

## 6. 权限与审计

新增 `analytics:*` 权限覆盖六类查询和事故结论、评价配置/生成/发布/申诉/复核、报表生成/导出。所有写操作继续调用既有审计服务；监管账号按组织及下级组织过滤，企业账号强制按关联企业过滤。

## 7. 验收门

- Prisma schema 校验、增量迁移、种子数据执行成功。
- NestJS 与 Vue TypeScript 生产构建通过。
- 单元测试覆盖周期校验、图表轴上限和透明加权评分。
- Playwright 覆盖六个监管页面、ECharts、高德风险图/轨迹、企业端评价与画像、移动端无页面级横向滚动、企业数据范围隔离。
