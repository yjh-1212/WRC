# 协同督办统一办理（2026-10-29）

用户确认保留“协同督办”名称，原风险通报、督办任务、跨市协同、应急统筹合并为一个直接导航入口。一个事项拥有多个地市承接记录，省级负责派发和复核，地市负责本市响应及反馈。

## 本次交付范围

- `/province/coordination`：查询条件在上、统一事项列表在下；类型、责任城市、状态、截止日期、关键词筛选；待响应、办理中、待复核、逾期快捷筛选。
- 四种事项类型共用新建、草稿修改、派发、地市反馈、退回补充和复核办结流程。
- 跨市事项设置牵头市和配合市，牵头市必须属于参与城市；根据用户最新要求移除应急资源入口、资源选择和资源详情；应急统筹保留为交办事项类型。
- 专项排查作为督办任务模板：统一检查清单，地市填报企业数、车辆数、问题车辆数、已整改车辆数及逐项检查结果。省级汇总仅计入已提交或已办结的反馈，退回后保留表单供补充，不计入有效汇总。
- 关联车辆、告警或事故，按具体业务权限及责任城市范围验证；关联对象跨市时禁止误交办到不包含该对象的城市。
- 地市仅返回自身承接记录、反馈及共同任务要求，不返回其他城市反馈、资源联系人或关联对象的原始数据。
- 老地址和从监测、事故、驾驶舱进入的上下文继续兼容；事项办结不自动修改原告警、事故的处理状态。

## 办理与恢复规则

新建为草稿，派发后要求与参与城市不可直接修改。省级逐市复核，也可以在全部城市提交后整体复核。仅已提交反馈可办结，反馈不充分可以退回。专项排查数量必须满足：已整改车辆数 ≤ 问题车辆数 ≤ 排查车辆数；所有检查项都需填报，发现问题或不适用时需说明。省级判断反馈是否充分，不以自动统计代替复核。

普通事项可选期限；专项排查需明确期限。派发时再次校验期限、城市和关联资源。资源占用、释放沿用事务保护。既有历史事项兼容默认普通模板，未补录牵头市的历史跨市事项展示为“参与地市”。

## 界面约定

沿用已确认的白底、蓝色控件、轻边框和紧凑表格，不新增四类功能标签页和顶部统计卡片。表格展示事项类型、责任与牵头城市、反馈进度、截止时间、状态及操作。详情展示办理要求、关联线索、分市反馈、专项排查汇总和过程记录。新建表单按类型展开分工、清单字段；编辑和反馈草稿按账号及事项保存在当前浏览器，失败不清空，关闭未保存表单需提示。

## 验收范围

导航直接进入统一页面；旧链接保留筛选和新建上下文；创建、派发、地市响应、结构化反馈、退回、再次提交及复核办结；跨市越权拦截、无权限关联资料拦截、资源占用冲突；汇总口径与分页筛选；桌面和窄屏布局、错误重试与草稿恢复。
