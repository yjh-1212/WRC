# 地市线下申请与省级直接开通

地市通过线下提交申请。省级管理员在“地市管理 → 城市管理”点击“开通城市”，录入城市、管理单位、联系人、管理员账号及初始密码，配置模块、有效期与车辆配额后直接开通。线下依据可记录授权函编号或办理说明。

保存成功后，城市和管理员账号立即有效，无线上申请、审核、补正或首次激活环节。界面展示开通结果和管理员账号；省级将账号及设置的初始密码交付给负责人，地市通过统一登录入口使用。密码仅以哈希保存，不进入响应、配置或审计详情。

开通在一个数据库事务内完成机构、城市、城市角色、审批流程、管理员、通知和审计日志的初始化；失败整体回滚。城市编码、机构关联和管理员账号不能重复。只有具备组织管理写权限的省级监管人员可以开通，市级、企业及运维账号均不可执行。

功能调整、续期及管理员变更同样线下联系省级，由已有授权调整、邀请或恢复管理员能力办理。旧线上申请数据和材料保留，旧开通审核页面跳转到城市管理；公共申请页面改为线下办理说明，新的线上申请与变更提交返回 410。
